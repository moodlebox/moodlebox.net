We're proud to celebrate __10 years of MoodleBox__ with the release of MoodleBox image [version 4.12.0][release]. Built with a strong focus on stability, reliability, and sustainability, this milestone strengthens the foundation for the years ahead.

{{< figure src="/img/media/ten-years.png" width="300" class="centered-image" alt="MoodleBox turns 10" >}}

MoodleBox image [version 4.12.0][release] was released on October 4, 2026, at the same time as [Moodle 5.3][moodle53] (_Long Term Support_). It is based on the latest Raspberry Pi OS Lite.

Here are the main new features of release [MoodleBox 4.12.0][release]:
- [Moodle][moodle] [version 5.3][moodle53] (_Long Term Support_)
- Based on the latest version of [Raspberry Pi OS Lite][rpios] of September 15, 2026
- The latest version of the [MoodleBox plugin for Moodle][plugin]
- Other improvements and fixes, focusing on stability, reliability, and sustainability

MoodleBox installation requires the use of the latest version of [Raspberry Pi Imager][rpi-imager] utility, which will automatically download the MoodleBox disk image for you.

&Gt; [More information about MoodleBox installation][install]

Have a look at the [release notes on Github][release] for all info about this release.
